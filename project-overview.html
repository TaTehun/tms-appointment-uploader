// technical_highlights

WIDGET
Time Fields by JS
The time boxes keep the Initial value and validate on blur. Setting value at once and firing one change avoids the Invalid Time alert.
FRAMES
Nested Frame Switching
Navigation lives in one frame and content in a shell → result frame pair; each screen step switches explicitly before it reads.
FILTER
Form-Ready Rows Only
Initial and Reschedule rows missing any form field are skipped. Reschedule reads the latest filled round of 2nd–5th.
ROUTING
Merged-Cell Lookup
The region sheet lists a location once above its Plan IDs; the reader carries the last location down to build Plan ID → team.
COST
No Browser When Not Needed
Modification and Cancel never touch the TMS form, so a run with only those never launches Chrome.
SAFETY
Human-Confirmed Submit
Until sign-off, a person presses Submit and answers the prompt; a reported failure raises before the master is marked done.

// error_handling

Missing Form Field
Row skipped without a write; it is picked up once the booking bot fills the field.
Plan ID Not on Screen
RuntimeError lists the Plan IDs that were visible, so the cause is in the log.
Invalid Time Alert
Avoided by replacing the time value through JS and firing a single change event.
Submit Reported Failed
input() answer 'n' raises before mark_uploaded(), so the row stays at Stage 2.
No Recipient
Plan ID not in the region sheet → warning, mail skipped, upload still recorded.
Unhandled Error
Exit code 1 at once; the tracker mails the failure from the exit code.

// dev_process · Claude Code Conversations · paraphrased from working sessions

Time Fields Kept Failing
TJ
The reschedule form's time boxes already hold the Initial time, and typing into them throws an Invalid Time alert. Don't type: set the whole value and fire the page's own change handler once.
C
_set_time() assigns value through execute_script and dispatches a bubbling change event, which runs copyTime/checkTimeFormat on the complete value. Date fields stay on clear() + typing.
Read the Shared Master, Not a Copy
TJ
Read the same master the booking bots write: Outbound rows at APPT Scheduling C or F and Process Stage 2. The master stores request types as I/R/M/C; map them back to full words at read time so the rest of the code doesn't change.
C
get_pending() applies REQUEST_TYPE_MAP on read and skips form-incomplete Initial/Reschedule rows. mark_uploaded() sets the upload status and Stage 3.
Skip the Browser for M and C
TJ
Modification and Cancel only need the result file and the mail; they never open a TMS screen. If those are the only pending rows, don't launch Chrome at all.
C
needs_browser checks for any Initial/Reschedule before the uploader logs in; run() calls upload() only for those two types.
Submit Stays Manual for Now
TJ
Write the Submit click but keep it commented out. Until it's approved, I press Submit myself; ask me afterwards, and if I say it failed, don't mark the row uploaded.
C
confirm_submit() prompts after the form is filled; 'n' raises, so mark_uploaded() never runs for that Load.
